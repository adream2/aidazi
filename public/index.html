    关于爱打字

    一个纯前端的打字练习工具，做给自己用，也顺手开源出来。

    爱打字（aidazi）是一个免费的在线打字练习站，覆盖中文与英文两类需求：英文练习看 WPM（每分钟词数），中文练习提供拼音、五笔 86、双拼、笔画四种输入路径，其中双拼包含小鹤、微软、搜狗、智能ABC、自然码五套方案。除练习本身外，站点还整理了 86 版五笔字根口诀与字根表、双拼键位对照、指法分区与练习阶段、键盘配列与轴体图鉴等资料，方便边练边查。

    站点为纯静态页面，没有账号体系：不需要注册、不收集输入内容，练习成绩只保存在你自己的浏览器里。五笔编码与笔顺数据来自公开码表，由构建脚本生成；双拼键位经各方案公开文档核对。项目由 ZT折腾簿 维护，源码在 GitHub 上开放，欢迎提 issue 或 PR。

    常见问题

    第一次用之前，通常想知道这几件事。

    爱打字是什么？需要付费或注册吗？

    爱打字是一个免费的在线打字练习站，提供英文、拼音、五笔 86、双拼、笔画五种练习模式，并附字根口诀、键位对照与键盘图鉴。不需要注册、不需要安装，打开网页即可练习。

    支持哪些双拼方案？

    支持小鹤双拼、微软双拼、搜狗双拼、智能ABC双拼、自然码双拼五套方案。练习时虚拟键盘会实时显示当前方案的声母/韵母键位，并高亮下一个待按键。

    五笔练习是哪个版本？编码准确吗？

    使用 86 版五笔。默认按最简码输入（与真实输入法一致），可切换全码练习。编码来自公开的 86 版码表，收录 1200 个常用字，并与码表交叉校验。

    笔画输入法怎么操作？

    五种基本笔画对应：横 = 1 或 h、竖 = 2 或 s、撇 = 3 或 p、捺 = 4 或 n、折 = 5 或 z。按汉字的规范笔顺依次敲击即可，例如「十」= 横竖 = hs，「人」= 撇捺 = pn。

    练习成绩保存在哪里？

    成绩（速度、准确率、各组最佳记录）保存在浏览器的 localStorage 中，不会上传服务器；换浏览器或换设备不会同步。

    拼音模式的流程和真实输入法一样吗？

    一样。输入拼音后出现候选栏（词优先、单字随后），用空格或数字键选字上屏；拼音没输完就选字、或选错候选都会判错并提示，用来练习「见字打词」的整句手感。
